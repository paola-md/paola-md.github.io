# paola-md.github.io

Source for [paola-md.github.io](https://paola-md.github.io), my academic site.

Static HTML, no build step. Publications, experience, teaching, supervised students,
talks, awards and media, generated from my OpenAlex record and CV.

Built to be readable by machines as well as people:

- Highwire Press citation tags (`citation_title`, `citation_author`, `citation_doi`,
  `citation_pdf_url`) and Dublin Core on every paper page
- schema.org `Person`, `CollectionPage` and `ScholarlyArticle` JSON-LD
- abstracts as HTML text rather than PDF-only
- `robots.txt` that explicitly allows AI crawlers, plus `llms.txt` and `sitemap.xml`

Typeset in New Spirit and Inter.
